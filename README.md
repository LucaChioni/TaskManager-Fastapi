# Task Manager API

Task Manager API is a backend practice project built with **FastAPI**.
The project focuses on API development, authentication, database integration and Docker-based development workflows.

## Tech Stack

* Python
* FastAPI
* Uvicorn
* SQLAlchemy
* MySQL
* JWT authentication
* Docker

## Features

* Task CRUD operations
* User registration
* User login
* Password hashing
* JWT-based authentication
* MySQL database integration
* Docker development environment
